# Jabberrs YouTube Fix (Cydia Repository)

A custom Cydia repository hosting tweaks and patches to restore YouTube connectivity on legacy iOS devices (iOS 3 through iOS 6).

## 📱 How to Add to Cydia

1. Open **Cydia** on your jailbroken iOS 3, 4, 5, or 6 device.
2. Tap on the **Sources** tab at the bottom (or **Manage > Sources** on older versions).
3. Tap **Edit** in the top-right corner, then tap **Add**.
4. Enter the repository URL:
   ```text
   [https://jabber403.github.io/jabberrs-yt-fix/](https://jabber403.github.io/jabberrs-yt-fix/)
